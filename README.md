# 俄罗斯方块 Tetris

纯前端单文件实现的经典俄罗斯方块。双击 `index.html` 即可开玩，**无需安装任何依赖、无需构建、无需联网**。


## 操作方式

| 按键 | 功能 |
| --- | --- |
| `←` `→` | 左右移动 |
| `↓` | 软降（每格 +1 分） |
| `↑` 或 `X` | 顺时针旋转 |
| `Z` | 逆时针旋转 |
| `空格` | 硬降（每格 +2 分） |
| `C` | 暂存方块（每块限一次） |
| `P` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

## 功能特性

- **标准 7 种方块 + 7-bag 随机**：每 7 块必定包含全部类型，长期分布公平，不会连续出现同一个方块
- **下一块预览 + 暂存位**：暂存与取出随时切换，每块只能暂存一次
- **幽灵落点**：虚线实时显示当前方块将落到的位置
- **旋转墙踢（Wall Kick）**：贴墙、贴地时也能顺利旋转
- **计分与升级**：消 1/2/3/4 行分别得 100/300/500/800 × 当前等级；每消 10 行升 1 级，下落速度从 1 秒/格逐渐加快到最快 0.08 秒/格
- **背景主题自定义**：
  - 6 套预设配色（星云暗 / 深海蓝 / 丛林暗绿 / 酒红 / 纸白 / 樱粉）
  - 取色器可选任意背景颜色，面板、边框、文字、棋盘底色、强调色会按所选色相自动派生
  - 浅色背景自动切换为深色文字与深色网格线方案，不会出现「白字白底」
  - 选择结果通过 `localStorage` 记忆，下次打开自动恢复
- **消行闪光动画、暂停界面、游戏结束统计**

## 本地运行

直接用浏览器打开 `index.html` 即可。

如需通过本地服务器访问（例如测试移动端）：

```bash
# 任选一种
python -m http.server 8000
npx serve .
```

然后访问 `http://localhost:8000`。

## 技术说明

- 零依赖、零构建，单文件约 20 KB，无外部资源请求
- 渲染使用 Canvas 2D；游戏循环基于 `requestAnimationFrame`，下落节奏与帧率解耦
- 配色系统基于 HSL 色彩空间推导，只输入一个背景色即可生成整站协调配色
- 兼容 Chrome / Edge / Firefox / Safari 等现代浏览器

## 开发提示

想调整手感或难度，可修改 `index.html` 顶部的常量：

| 常量 | 含义 | 默认值 |
| --- | --- | --- |
| `COLS` / `ROWS` | 棋盘列数与行数 | `10` / `20` |
| `CELL` | 单格像素尺寸 | `30` |
| `COLORS` | 7 种方块颜色 | 见源码 |
| `KICKS` | 旋转墙踢偏移序列 | 6 组候选偏移 |
| `dropInterval` | 初始下落间隔（毫秒） | `1000` |
